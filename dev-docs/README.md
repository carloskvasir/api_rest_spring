# Documentação de Desenvolvimento (Dev-Docs)

Este diretório armazena a base de conhecimento do projeto, planos, e Registros de Decisões de Sistema (SDR - *System Design Records/Reviews*).

## Estrutura
- `/SDRs/`: Histórico de decisões técnicas significativas. 

> Baseado nos princípios de **System Design Review (SDR)** detalhados por Bruno Russo, a criação de SDRs serve como governança para promover a detecção precoce de falhas, melhoria da qualidade da arquitetura, redução de custos com retrabalho, além da garantia de segurança e facilitação da comunicação entre os envolvidos. A omissão deste passo acarreta problemas de escalabilidade e riscos elevados ao projeto.
