# Documentação de Desenvolvimento (Dev-Docs)

Este diretório armazena a base de conhecimento do projeto, planos, e Registros de Decisões de Sistema (SDR - *System/Software Design Records*).

## Estrutura
- `/SDRs/`: Histórico de decisões técnicas significativas. Sempre que uma decisão impactar arquitetura, banco de dados ou bibliotecas core, crie um novo SDR.
